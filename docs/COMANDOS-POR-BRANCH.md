# Comandos curtos para dar ao agente (um por vez)

> Para o responsável, não para colar de uma vez. Depois de revisar o diff e integrar a branch anterior, envie o próximo.

Modelo: `Execute a branch <N> (<nome>) do docs/plano-implementacao.md. Siga o protocolo da seção "Protocolo de cada branch", carregue as skills aplicáveis e, ao terminar, entregue o relatório e pare.`

|---|---|
| 1 | Execute a branch 1 (`chore/integrar-base`) |
| 2 | Execute a branch 2 (`feat/fundacao`) |
| 3 | Execute a branch 3 (`feat/schema-e-seeds`) |
| 4 | Execute a branch 4 (`feat/audit-core`) |
| 5 | Execute a branch 5 (`feat/sessions`) |
| 6 | Execute a branch 6 (`feat/auth`) |
| 7 | Execute a branch 7 (`feat/authorization`) |
| 8 | Execute a branch 8 (`feat/users-admin`) |
| 9 | Execute a branch 9 (`feat/tools`) |
| 10 | Execute a branch 10 (`feat/ai-chat`) |
| 11 | Execute a branch 11 (`feat/audit-consulta`) |
| 12 | Execute a branch 12 (`feat/frontend`) |
| 13 | Execute a branch 13 (`chore/validacao-final`) |

Entre uma branch e outra: revise o diff (`git diff`), confira que só o módulo da tarefa mudou, rode os testes e integre. Se o agente repetir um erro duas vezes, ajuste a skill ou a descrição correspondente.
